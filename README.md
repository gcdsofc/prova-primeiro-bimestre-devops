## Descricao do projeto

Projeto pratico da prova do primeiro bimestre da disciplina de DevOps.

A proposta e construir a API de Reservas da TechNova aplicando os conteudos das aulas 01 a 07: Git, Docker, Docker Compose, Terraform, AWS Academy, VPC, EC2, RDS, remote state, modulos e IA como copiloto.

A API sera desenvolvida em Node.js/Express, com persistencia em PostgreSQL, e tera CRUD completo para reservas com os campos:

- id
- cliente
- data
- status
